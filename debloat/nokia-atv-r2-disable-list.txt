# Nokia Smart TV "ATV R2" (maker SCBC, Android 11, Realtek RTD285O) - apps switched off with
#   pm disable-user --user 0 <package>      (nothing is uninstalled; "restore" switches them back on)
# Tested on firmware V8-T851TNF-LF2V287 (checked on 2026-10-20): the TV restarted normally, Netflix and
# YouTube opened, the Bluetooth remote and voice search worked, and all of these stayed off after a restart.
# One package per line. Everything after a # is a comment. Read docs/nokia-atv-r2.md before you apply it.

com.google.android.feedback                # Google feedback / bug reporting
com.google.android.marvin.talkback         # TalkBack screen reader - REMOVE THIS LINE if anyone using the TV needs it
